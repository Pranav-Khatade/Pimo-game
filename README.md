#🎮 Pimo - 2D Adventure Platformer Game

**Pimo** is a handcrafted 2D platformer game built using the **Godot Engine**, where the player embarks on a journey through 5 uniquely themed levels — Ground, Underground, Upper Sky, Underwater, and Castle.

Each level presents its own set of enemies, traps, and environmental effects (like ice-sliding), requiring the player to collect a key to progress to the next stage. The game combines classic retro mechanics with modern design aesthetics.

## 🌟 Features

- 🎮 Fun and responsive platformer mechanics
- 🧊 Ice blocks with sliding physics
- 🔑 Key collection to unlock next levels
- 🚪 Doors, traps, and enemies to navigate
- 🎨 Pixel art style with engaging visuals
- 🔊 Sound effects for coins, keys, and actions

## 📂 Built With

- [Godot Engine](https://godotengine.org/)
- GDScript
- Pixel Art Assets

## 🧠 Inspiration

Inspired by classic platformers like *Super Mario*, **Pimo** adds creative twists with a level-unlocking system and environment-specific mechanics to make gameplay fresh and exciting.
